Where the source code of every program in this package comes from
==================================================================

The launcher (GPL-3.0-or-later)
  https://github.com/akitaonrails/rea-teknoparrot-initial-d-series
  (the source archive of each release is on its GitHub release page)

windowsarcadeloader (GPL-3.0-or-later): components/wal
  https://github.com/aderumier/windowsarcadeloader at commit
  4f42c6d86ddaaa9d2e4e8c21e0046bb3027b111d, with the launcher's patches/wal
  applied (in the launcher's source: patches/wal/*.patch).

Flycast (GPL-2.0), Windows package only: components/flycast
  https://github.com/flyinghead/flycast/tree/v2.7 (release v2.7, unmodified;
  its licence is licenses/Flycast-LICENSE.txt)

Microsoft Visual C++ 2008 SP1 Redistributable (x86), Windows package only:
components/vcredist (Microsoft's own installer, unmodified, not open source;
installed by the launcher on the first start of Initial D 6, 7 or 8)
  https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

Microsoft DirectX End-User Runtime (June 2010), Windows package only:
components/directx (Microsoft's DXSETUP and the cabinet of XAudio2 2.3,
unmodified files from Microsoft's package, not open source; run by the
launcher on the first start of Initial D 6, 7 or 8)
  https://download.microsoft.com/download/8/4/A/84A35BF1-DAFE-4AE8-82AF-AD2AE20B6B14/directx_Jun2010_redist.exe

GE-Proton (Wine and its components; LGPL-2.1 and others), Linux package only:
components/runner
  https://github.com/GloriousEggroll/proton-ge-custom/tree/GE-Proton11-13
  (release GE-Proton11-13, unmodified)

winetricks (LGPL-2.1), Linux package only: components/winetricks
  https://github.com/Winetricks/winetricks/tree/20260125 (unmodified)

SDL 2 (zlib)
  https://github.com/libsdl-org/SDL (release 2.32.10 on Windows; Debian
  bookworm's libsdl2 on Linux)

lindbergh-loader (CC BY-NC-SA 4.0) is not in this package: the Linux
launcher builds it on your computer from
https://github.com/lindbergh-loader/lindbergh-loader at commit
0af606d845b70339c335785c0eba68b47b78df3c with patches/lindbergh applied.
