initiald-launcher — the Initial D arcade series

  initiald-launcher                          open the window (games, settings, controls)
  initiald-launcher --library <folder>       add a folder with your games (repeatable)
  initiald-launcher --naomi2-bios <file>     where your naomi2.zip is (Ver. 1–3)
  initiald-launcher --list                   list the games found and their state
  initiald-launcher --check [<game>]         check a game (or all) can start, without starting
  initiald-launcher --play <game> [options]  start a game (id1, id2, id3, id4, id5, id6, id7, id8, zero, ta3, ta5)
  initiald-launcher --set <game> <options>   save options for a game without starting it (also --game)

Options (saved in that game's settings):
  --look original|recommended|steam_deck  Look
  --render <WxH|native>                   Game render size
  --output <WxH>                          Output size (Linux helper)
  --upscaler fsr|nis|linear|nearest       Upscaler (Linux helper)
  --sharpness <0-20>                      Sharpness (Linux helper)
  --crt off|lottes                        CRT look (Linux helper)
  --fullscreen on|off                     Fullscreen (Linux helper)
  --deadzone <0.00-0.30>                  Dead zone

Test options for --play:
  --headless               run in an invisible display
  --no-input               no controller input
  --input-script <file>    timed inputs
  --seconds <n>            stop the game after n seconds
